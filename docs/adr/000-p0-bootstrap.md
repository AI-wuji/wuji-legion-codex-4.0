# ADR-000：先建立隔离的P0审计目录

日期：2026-10-02。状态：建设期记录，不改变已批准架构。

历史v1.5计划P2才启动Go/SQLite核心；2026-10-03已被v1.6的Rust小核心＋SQLite替代，阶段门保持不变。P0先在独立4.0目录保存只读采集工具和派生审计文件，避免继续往3.0开发目录混入新运行内容。这不视为P2放行、专家创建或生产安装。

允许：全新开发审计辅助工具、检查来源元数据/hash、读取原文、生成证据账与风险记录。

不允许：复制旧实现/模板/测试；核心源码、正式专家注册表或批量原子定义越过G0/G1；修改Codex、执行外来脚本、付费API、发布、音频硬件变更。

P0工具不会被装成Skill/MCP/后台服务；后续核心仅消费已校验的来源/设计契约，不以审计程序代替宿主能力。成熟依赖须从其上游独立核验和锁定。
