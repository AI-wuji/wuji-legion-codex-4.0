# ADR 001：先检索已有实践，再决定是否自行验证

日期：2026-10-03。状态：用户已明确要求，建设期立即适用；4.0运行契约与路由接线仍须在P1/P2实现，不能据本ADR宣称运行功能已完成。

## 决策

面对新想法、技术选型、架构、融合、性能、兼容性、故障根因等实质性问题，先找已有相同或相近实践及其验证结果，再制定方案。不能默认自己的想法独创，也不能把“先实现一个试验再说”作为常规第一步。

顺序：明确问题与约束 → 查询已有来源账与有效研究 → 全网检索同类成功/失败实践 → 追到原始出处与实现 → 判断证据适用范围 → 复用已有结论/方法/工具 → 仅对仍然影响决定的证据缺口进行必要验证。

已存在足够匹配的成熟实践时，直接以其作为选型和方案论证依据，不重做公开结论的证明；外部有效结论可结束研究分支，不增加形式性的“本地再证一次”节点。简单任务直接完成；已有有效、可定位的结论不重复搜索。此规则不是每轮固定长篇调研，也不是默认多模型/多代理评委。

## 搜索与证据

- 用问题而非预定答案检索，包含症状/机制/平台/版本/约束；同时找失败案例、代价及相反路线，避免只证明自己喜欢的语言。
- 全网检索用于发现，技术结论优先项目作者文档、公开实现、发布记录、原始论文及公开测试/生产案例；社区可提供线索，但不能凭重复转述把猜测升格为事实。
- 分开记录作者的设计理由、公开实现存在、实际采用/运行案例、测量结果和自己的适用性推断；仓库README不是本项目所有指标的验证报告。
- 保存原始URL、发表/观察日期、定位、适用版本/环境、支持和不支持的声明。历史规划与当前落地状态分别核对，项目更名/重定向保留别名。
- 找到足够证据且新搜索不改变选项、边界或决定时停止，不为了“全网”做无穷扫描；“本轮未找到”不宣称“世界上没有”。
- 公开检索不包含用户私有源码、凭据、私有URL或原始聊天；需要外发私有材料时另核授权。

## 什么时候才自行验证

仅当公开/既有证据不足、冲突无法消解、所需环境或版本差异未覆盖、或问题本身是本次实际成果是否做成时，定位具体缺口。若缺口不影响决定，明确局限后继续，不设额外阻断门。

需要验证时，仅验证缺口的最小部分；不能重写整个候选系统、做无预算性能竞赛或强行测收费API。涉及安装、付费、发布、音频及系统设置仍按既有授权边界。

用户在语言研究轮明确不要求本地选型验证：当轮只进行网上研究及文档更新。随后“先修订1.5再执行”授权继续建设P0—P6；不把研究轮的只改文档误当成持续建设暂停令。仍不做默认性能/协议选型试验、不自动付费；本项目真实实现与交付完整性检查不由外部案例冒充。

外部证据作为方案依据，不改记为本地执行。比如“Temporal已经用Rust连接Python”支持路线可行；它不是“本机4.0的Python适配器已经运行”。同理，本次成果验收不应伪称由别人项目的测试完成。

## 在4.0中的设计落点

- 阿极/负责人：提出结构化问题和需决定的关键项，不先创建研究团队或实验任务。
- 研究职责：按范围搜索、抽取、追源、对照反证及给出带出处的结论；不承担安装/发布。
- 技术与经验来源账：同一条进化链记录外部已验证实践及本地经验，类型、scope和证据等级不同，不新增第二知识权威。
- 配方规划：已有充分证据直接选用；缺口才生成有输入、owner、预算和停止条件的验证节点，不把研究本身包装成常驻服务。
- 发布与更新：新来源触发适用消费者与反向影响检查，只修订相关方法/适配器，不把一个案例推广成所有专业硬律。

拟冻结字段：question、decision_needed、prior_source_refs、matching_constraints、external_evidence_kind、counterevidence_refs、applicability、decision、remaining_gap、experiment_needed及reason。它们是设计字段，未生成运行schema/核心实现。

## 正反场景

- Rust核心与跨语言兼容：已有Temporal Core、Goose和Codex源码先例，先借其工程结论，不先编两套核心做对照。
- 模型当前端点/免费额度：公开产品通用能力不证明私有供应商实际账户条件；保持unknown，不换模或自动付费。
- 已知公开库缺陷：先查对应版本issue/release与修复，不先重新猜根因；现象不同则限缩缺口。
- 用户仅要求改一句话：直接改，不拉研究团队、不搜索无关技术。
- 专业成品：用公开方法指导制作，但不把他人的成品/测试作为本次文件已生成的证据。

## 影响

这项用户要求立即修正此前“先自做语言/兼容性可行性实验”的建议。G0/G1/P7的既有权限和真实性边界不因此假通过；语言架构已按最新明确指令纳入v1.6。原始资料只读，旧实现不搬进4.0。
