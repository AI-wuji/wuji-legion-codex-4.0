# LibreOffice 单消费者上游核实：2026-10-06

## ResearchDecision

**本轮保留已安装的 LibreOffice 26.8.0.3 作为待验收消费者的精确锁，不升级、不运行；不能写成“已采用官方最新公告版本”，也不能据此判定 T55 全部通过。** 本文只核实这一个消费者，不扩展为全部依赖准入。

核查基准为 **2026-10-06，Asia/Shanghai**；官方原始 HTTP 页面取得于当日 23:55–23:56。结论对应这个观察窗口，不保证镜像实际交付成功，也不把计划日期当成已发布日期。

### 差异、反证与适用范围

- **相对当前网页提供的 26.8.0：** 采用版在发行短版本上相符；这不能证明包目录始终同步、安装器当前可下载，或本机产品行为已验收。[S1][S6]
- **相对已公告的 26.8.1：** 差一个维护修复版。公告列出约 40 项修复，涉及 DOCX 目录链接、文字对齐和行距，XLSX 绘图及数据库区域，PPTX 导入崩溃，以及中文等文本/CSV 编码导入。RC1 修复清单比较基线为 26.8.0 RC3。[S10][S9] 这些是与办公消费者相关的升级理由，不是本轮样例必然命中缺陷的证明；也未证明现有公式重算缺口已被修复。
- **反对无条件追新：** 官方称 26.8 首发可能仍有待修复问题，同时维护更成熟的 26.2；生产环境可留在其支持期内的旧分支。反过来，这不构成长期保留 26.8.0 的无条件理由：26.8.1 公告建议 26.8 用户更新修复版，前提是交付恢复且本地重新获授权。[S2][S10]
- **兼容性例外：** 26.8 的官方功能说明明确区分 OOXML 图表的保留与实际渲染/编辑支持；部分新图表只能保留定义，区域地图内容也可能不能完整保留。发行说明还列出不再捆绑的 Gentium Basic / Gentium Book Basic 字体。[S12][S8] 因而“可打开”不等于所有内容、字体或版式保真。本文不把这些说明当成本机渲染测试。

### 保留旧版本的条件

以下为**本项目建议**，不是把官方公告改写为本机授权：

1. **当前 26.8.0.3：** 本轮只保留现状及可追溯精确锁；Office 工作仍停止、完整消费者验收未闭合。保留不等于批准生产使用或证明无安全缺陷。
2. **后续更新：** 若 26.8.1 的正式交付恢复，且该消费者确需上述修复，应在新的明确授权下评估更新；只做受影响的内容、公式与版式验收。当前不安装、不试运行、不连接或查询打印机。
3. **既有 26.2 生产消费者：** 官方支持期和成熟分支建议可以构成继续保留的依据，但需要实际兼容性需求、受支持的维护版以及到 2026-11-30 前的迁移安排。不能把这一例外套用成本项目已经改用了 26.2。[S2][S10]
4. 若出现影响消费者的安全公告、支持终止、确认的数据损坏/兼容性问题，或新授权要求变更，需重新审查保留决定；本轮没有进行全量安全公告审计，不声称不存在此类问题。

## 剩余 unknown 与来源冲突

- **镜像交付状态：** 状态页显示下载服务 Operational，且说明绿灯不保证不存在未登记故障；26.8.1 公告仍含延迟提示，主下载页仍为 26.8.0。尚不能确认延迟何时解除、26.8.1 安装器的实际交付及校验状态；没有据状态灯推翻公告，也没有下载或执行安装器。[S7][S10][S1]
- **26.2.6 的精确发布日期：** 当前发布说明写 **2026-09-24**，官方公告正文及问答写 **2026-09-04**。来源存在冲突，权威统一发布日期为 **unknown**；版本本身及双分支事实可交叉确认。该冲突不改变本轮保留现状的决定。[S2][S11]
- **候选日期与产品日期：** 既有包目录的 Release Date 为 **2026-08-24**，而官方产品发布说明和公告为 **2026-08-26**。前者只是候选元数据，不能反推产品公开发布日；差异原因未核实。[S2][S12]
- **检索/读取差异：** 初始检索给出的若干公告 URL 在原始 HTTP 抓取中返回 404；从官方站点实际导航定位到本文 [S10]–[S12] 的正确 URL 后已取得 HTTP 200 正文。失败响应保留为访问证据，不当成目标公告正文。26.8.1 公告日期按正确正文的 **2026-10-02**，不采用旧检索定位中的 2026-10-01。
- **消费者效果：** 本轮未启动任何 Office 程序，未做 COM、转换、重算、渲染或打印相关操作。既有公式重算及完整视觉验收的未完成项仍未闭合；新修复是否解决这些项目为 unknown。
- **范围结论：** 已补本消费者的上游一手来源、版本比较、反证、例外及剩余缺口。不是 T55 全局通过，不更改正式历史验收账，也不宣称其他依赖或全部 Office 准入完成。
