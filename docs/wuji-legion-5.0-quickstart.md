# 无极军团5.0快速开始

本文说明仓库中的5.0项目入口。它不代表5.0已经安装到某个用户的全局 Codex 环境；全局部署状态必须在实际目标机回读确认，且不写回共享项目源 manifest。

## 使用

直接向阿极描述目标、输入、交付物和限制。简单任务由阿极直接完成；只有确有专业能力或独立工作分支时，才使用当前会话实际提供的 Skill、MCP、工具或原生子代理能力。

不得要求用户运行仓库 CLI 来激活5.0。项目内 CLI 和 app-server 适配仅用于有界诊断或辅助，不等同于当前会话的原生专家执行。当前会话没有相应能力时，由阿极直办或说明限制，不以旧版路由、fixture、目录或契约冒充执行。

## 项目入口

- 项目规则：仓库根目录 `AGENTS.md`
- 活动 Skill 源：`legion/skills/wuji-legion-5-0/SKILL.md`
- 活动项目 manifest：`legion/task-entry-5.0.json`
- 全局安装与验收契约：`legion/skills/wuji-legion-5-0/references/installation-contract.md`
- 4.0资料：只读历史，不加载旧角色链、路由或执行命令

manifest 中的入口和路由路径均相对于 manifest 所在目录。`project_entry_active` 只表示项目源的入口状态，不表示全局 Skill 已安装、自动发现或已在新会话生效。

## 全局部署状态

本项目的5.0包可以先在仓库内审查和验证。只有用户明确要求部署后，才把精简后的5.0稳定规则合并进用户级 `AGENTS.md`，并把完整 Skill 目录安装到目标 Codex 的用户 Skill 目录。部署后回读文件、核验 Skill 元数据与相对引用，并在新会话观察发现状态；每一项分别记录，不把文件复制成功等同于行为验收通过。

全局规则和 Skill 仅提供指引，不覆盖系统/宿主指令，不授予工具权限或用户未授权的副作用操作权限。不得擅自修改模型/provider、凭据、插件、MCP或其他全局设置。

## 能力与状态

- 专家委派：只使用当前会话实际提供的原生能力；不可用时直办或降级。
- 并发：只并发已就绪、互相独立、权限允许且写集不冲突的分支。
- 安装：项目源状态、文件已复制、Skill 已发现、新会话行为观察分开记录。
- 证据：区分请求、配置、观察和有效状态；失败或未知如实保留。
