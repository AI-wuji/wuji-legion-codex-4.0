# 写作、办公、演示与业务协作

适用：长文/商单/课程与平台适配、DOCX/PDF/XLSX/CSV、可编辑PPTX/HTML演示、数据报告，以及文档/知识库/表格/任务/日历/邮件/会议/审批/网盘等业务协作。普通改写、翻译直接完成。

## 先做用户真正要的文件
1. 确认事实输入、读者、文件格式、可编辑/离线要求和交付位置；需求已清晰就开做，不强制问卷、模板或人数编制。
2. 使用当前已可用的原生MCP、CLI、API或项目工具；OfficeCLI等具体入口需当前版本/身份/权限证明，目录名称不证明可调用。
3. 先形成真实正文、表格或页面，再按具体缺陷优化结构、表达和视觉；不要先建万能排版框架或默认常驻预览服务。
4. 进行与交付相匹配的读取、公式或渲染检查，交付可回读文件及真实限制；导出成功不等于可编辑、保真或专业效果通过。

## 专业验收按需选择
- 写作/课程：保留事实内核、术语、引用和训练目标；商单约束与交付清晰。风格只改允许的表达，不克隆专家或编造案例/竞品。
- 社媒/平台：同一事实可调整篇幅、语气和排版；本地稿、云草稿、上传与正式发布是不同动作，不能用用户要“写稿”授权发布。
- Word/PDF：关注段落层级、分页、字体、批注/修订及必要的可视检查；抽取文本或页图不冒充可编辑原件。
- 表格/数据报告：核公式、引用、单位、缺失值、分母、统计与图表对应数据；静态数字或截图不冒充公式与真实分析。
- PPTX：需要编辑时保留原生文字、形状、图表和表格，逐项确认实际对象与渲染；不能把整页图片当全可编辑。
- HTML演示：只有任务需要才提供交互、动画或讲者模式；离线依赖、浏览器编辑与PPTX/PDF出口分别验证，页面数不代表效果。
- 飞书等协作/网盘：确认目标对象、链接/ID、当前身份和授权范围；读取、写入、分享、发送、审批提交分别控制，不默认全库抓取或上传私料。

## 分工与回读
- 内容、图表、布局或数据可独立分工，但同一段落/工作表/页面有明确写权和合入owner；按输入变化只重做受影响部分。
- 远端多页结果保留游标和部分失败，游标无进展停止；发送/提交不明先查目标或回执，不重复造成多份业务事实。
- 风格和解释性评分不能抵消错误公式、失实、缺页、越权或不可编辑等硬失败；复核只处理实际风险或具体缺陷。
- 阿极返回真实文件/对象、可编辑与检查范围、未测能力、未执行的发布/分享等动作；“保存”不自动包含外发。
