# 图像、视频与声音的真实交付

适用：图像生成/编辑/反推、视觉资产与插画、视频/动画、剪辑/字幕、音乐与声音。单张图、局部修图或单纯音频不强制走完整视频流水线。

## 先绑定实际能力
- 记录当前输入、素材/人物ID、用途、输出规格、许可及必须保持/允许改变项；参考素材不是通用参数或上传授权。
- 优先已存在且本次可用的MCP/CLI/API或编辑软件入口，确认真实端点/工具版本、schema、身份和能力；未知时明确unknown，不靠工具名称编造可生成时长、音画同步或免费额度。
- 提示词、参数、工程准备与实际生成结果分开；无真实产物不能称已生成、已剪辑或已混音。

## 完整视频的必要顺序
1. **Story**：按用户目标形成叙事/信息骨架、真实内容时长与声画意图；不统一强推五幕、爆点频率或字数。
2. **真实音乐选择与预剪**：选本次获准可用音源，取得真实音频、实际试听/可用编辑检查和预剪片段；记录时长、节奏点与版本。文本BGM建议或假MusicCue不冒充这一产物。
3. **Shot**：消费Story与音乐预剪，写镜头画面、必要运动、时长、台词/字幕和声画关系；不强制每拍切镜、固定宫格或每镜若干候选。
4. **生成/剪辑与时间线**：按实际端点单元执行，核真实素材时长、连续性、时间基准和转场；粗剪先恢复结构，精剪才处理细节。用户内容时长不擅自改为工具方便的时长。
5. **最终声音**：在已确定时间线上处理对白/旁白、环境、动作音效、音乐、分轨/总线及混音；核字幕同步、可懂度、爆音与成片回放，最终声音不被前置音乐预剪替代。

## 窄专业分工
- 叙事/文案、视觉与资产、分镜、生成、剪辑、音乐和声音按实际任务共享调用；一个成片/时间线有一个合入owner，不创建万能媒体专家。
- 先做独立素材，消费上游版本的工作按依赖交接；变更Story、音乐或镜头仅失效相关下游，未知调用结果先查询，避免重复付费或重复导入。
- 图像检查身份、布局、指定保持项及必要alpha/尺寸；信息图与知识演示核事实，合成示范不能冒充真实操作屏录。
- 声音的pan不证明3D声场，分轨文件不证明真实混音；不为消除阻断改麦克风、声卡或系统音频链。

## 验收与限制
- 检查当前实际输出的画面、声音、字幕、黑帧、编码和可编辑工程；4K/60fps、固定混音数值或时长不是统一硬标准。
- 无可用工具、音源许可或零新增费用条件时，交付已完成部分和具体未做步骤；不能用占位文件、导演描述或假回执宣称全链完成。
- 阿极返回实际素材/工程/成片及回读位置、版本、检查范围与失败证据；上传、分享、发布和付费仍是另行受控动作。
